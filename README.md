# مشروع قارب الصيد الجزائري

قارب صيد صغير بمحرك خارجي، مرجعه **Polycraft 300 Tuffy**، مصنوع من **الألياف الزجاجية والراتنج** بمعايير عالمية، ومصمم هندسيًا بـ Rhino وMaxsurf، ومجهز بأحدث تجهيزات الصيد وبتشطيب راقٍ.

الهدف: أن نثبت أن اليد الجزائرية تصنع قاربًا بمستوى عالمي.

| | |
|---|---|
| **المصمم والمنفذ** | أيوب |
| **الحالة** | مرحلة التصميم: اتجاه المشروع نهائي (القرار 0003) |
| **المرجع** | Polycraft 300 Tuffy (3.07 × 1.56 م، محرك حتى 15 حصانًا) |
| **الورشة** | 8 × 4 م |
| **الميزانية الأولية** | 100,000 دج |

## طريقة العمل

1. نناقش نقطة واحدة في كل مرة.
2. عندما نتفق، يُكتب القرار في `docs/decisions/` ويُحدَّث جدول القرارات أعلاه.
3. كل رقم مأخوذ من مصدر خارجي يُكتب معه رابط المصدر. كل رقم تقديري يُكتب بجانبه «تقدير».
