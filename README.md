# مشروع كاياك الصيد الجزائري

كاياك صيد من نوع **sit-on-top** (تجلس فوقه لا داخله)، مصنوع من **الألياف الزجاجية والراتنج**، ومصمم هندسيًا بـ Rhino وMaxsurf لبحر الجزائر وللصياد الجزائري.

| | |
|---|---|
| **المصمم والمنفذ** | أيوب |
| **الحالة** | مرحلة التصميم: القرار 1 مُعتمد |
| **المرجع** | Perception Pescador Pro 12 |
| **الورشة** | 8 × 4 م |
| **الميزانية الأولية** | 100,000 دج |

## القرارات المعتمدة

كل قرار نتخذه يُسجَّل في ملف مستقل داخل [`docs/decisions/`](docs/decisions/)، مع سببه ومصادره. لا يتغير قرار معتمد إلا بقرار جديد يذكر ما ألغاه.

| رقم | القرار | الحالة | التاريخ |
|---|---|---|---|
| [0001](docs/decisions/0001-reference-kayak.md) | القارب المرجعي: Pescador Pro 12، ونسختنا من الألياف بحوالي 3.6 × 0.82 م | معتمد | 2026-10-02 |
| 0002 | تجهيزات السطح: ما نأخذه، وما نحسّنه، وما نحذفه | قيد النقاش | |

## أسئلة مفتوحة

- [ ] عرض باب الورشة وارتفاعه، وارتفاع السقف
- [ ] أسلوب الصيد في المنطقة: قرب الشاطئ أم بعيدًا في البحر؟
- [ ] مسح السوق: 20 إعلان كاياك على Ouedkniss (الماركة، الطول، السعر)

## تنظيم المشروع

```
docs/
  decisions/   القرارات المعتمدة، ملف لكل قرار
  research/    البحث: القوارب المرجعية والسوق
  workshop/    الورشة: القياسات والتوزيع والسلامة
design/
  rhino/       ملفات Rhino (.3dm)
  maxsurf/     ملفات Maxsurf (.msd) ونتائج الحسابات
```

## طريقة العمل

1. نناقش نقطة واحدة في كل مرة.
2. عندما نتفق، يُكتب القرار في `docs/decisions/` ويُحدَّث جدول القرارات أعلاه.
3. كل رقم مأخوذ من مصدر خارجي يُكتب معه رابط المصدر. كل رقم تقديري يُكتب بجانبه «تقدير».
