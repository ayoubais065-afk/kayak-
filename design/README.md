# ملفات التصميم

- `rhino/`: ملفات Rhino (`.3dm`): الهيكل، السطح، قوالب المقاطع.
- `maxsurf/`: ملفات Maxsurf (`.msd`) ونتائج Stability وResistance (تُصدَّر بصيغة PDF أو CSV).

## تسمية الملفات

`<الجزء>_v<رقم النسخة>.<الامتداد>`، مثال: `hull_v01.3dm` و`hull_v02.msd`.

كل نسخة جديدة تُرفع مع رسالة commit تشرح ما تغيّر.

## الملفات الكبيرة

إذا تجاوز ملف 50 ميغابايت، نفعّل Git LFS قبل رفعه.
