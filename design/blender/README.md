# سكريبتات Blender

## `cathedral_hull_from_offsets.py`

يبني هيكلًا ثلاثيًا (cathedral) ثلاثي الأبعاد من **جدول مقاسات (offsets)** مأخوذ من مخطط خطوط ثنائي الأبعاد.

- المرجع: `reference_lines_plan.jpg` (مخطط قارب روسي صغير، حوالي 3.6 م).
- **الأرقام الحالية في الجدول تقديرية بالعين.** قِس القيم الحقيقية من المخطط وعدّلها.
- يضيف مجموعة جديدة `Hull_Cathedral` فقط، ولا يغيّر شيئًا آخر في المشهد.

### أعمدة الجدول (بالمليمتر)

| العمود | المعنى | من أين يُقرأ |
|---|---|---|
| x | بعد المقطع عن المقدمة | المنظر الجانبي (المسافات بين المقاطع 0 إلى 7) |
| B | نصف العرض عند الحافة العلوية | المنظر العلوي |
| H | ارتفاع الحافة العلوية فوق خط القاعدة | المنظر الجانبي |
| ZK | ارتفاع قاع الهيكل الوسطي | المنظر الجانبي ومنظر المقاطع |
| ZS | ارتفاع قاع العوّامة الجانبية | منظر المقاطع |
| ZT | ارتفاع أعلى النفق بين الهيكل الوسطي والعوّامة | منظر المقاطع |
| ZC | ارتفاع خط التقاء القاع بالجانب (chine) | المنظر الجانبي ومنظر المقاطع |

### التحجيم

`TARGET_LENGTH = 3000` و`TARGET_BEAM = 1500` يحوّلان الهيكل إلى مقاسات قاربنا (القرار 0004).

### التشغيل

Blender ثم Scripting ثم Open، واختر الملف، ثم Run Script. أو أرسله إلى Blender عبر MCP (`execute_blender_code`).

## `setup_reference_images.py` (طريقة الصور الخلفية)

نفس طريقة فيديو [leçon N° 03 Rhinoceros: coque 3D par une image en arrière-plan](https://www.youtube.com/watch?v=FjSYE6Jbafo) (benzidane rachid)، مطبّقة في Blender:

1. يضع المنظر الجانبي (`profile.png`) في المنظر الأمامي لـ Blender (مستوى XZ)، والمقدمة عند X = 0 والمؤخرة نحو ‎-X.
2. يضع المنظر العلوي (`plan.png`) في المستوى XY، والخط الأوسط عند Y = 0.
3. يضع منظر المقاطع (`body_plan.png`) في المستوى YZ عند X = +0.6 م.
4. يرسم خطوط المقاطع 0 إلى 7 (`Station_Guides`) عند مواضعها الحقيقية.

الصور تظهر فقط في المناظر المتعامدة (أمامي، علوي، جانبي)، وهي مضمّنة داخل ملف .blend.

### المقياس

- **المنظر الجانبي والعلوي:** 4.92 مم لكل بكسل، محسوب من المسافات بين المقاطع (400 مم في المقدمة، 600 مم في الخلف). الطول من المقطع 0 إلى 7 = 3.6 م.
- **منظر المقاطع:** 3.07 مم لكل بكسل، من علامات 100 مم تحت خطوط Б1 إلى Б5.
- **تنبيه:** منظر المقاطع مرسوم بمقياس أكبر من المنظرين الآخرين، وبعض قياساته لا تتطابق تمامًا معهما (مثلًا الخط T). المخطط صورة من كتاب، وليس مخطط بناء دقيقًا. قارن العرض والارتفاع في منظر المقاطع مع المنظرين الآخرين، وصحّح مقياسه إذا احتاج.

### الخطوات بعد التشغيل (مثل الفيديو)

1. **المنظر الأمامي (Numpad 1):** ارسم بالمنحنيات (Add, Curve, Bezier) فوق الصورة: خط الحافة (П)، وخط الالتقاء (Сл)، والعوّامة (Сп)، والقاع.
2. **منظر المقاطع (Numpad 3):** ارسم نصف مقطع لكل محطة من 0 إلى 7.
3. **انقل كل مقطع** إلى X الخاص به (المقطع 0: X = 0، المقطع 1: X = ‎-0.4، المقطع 2: ‎-0.8، المقطع 3: ‎-1.2، المقطع 4: ‎-1.8، المقطع 5: ‎-2.4، المقطع 6: ‎-3.0، المقطع 7: ‎-3.6).
4. **اربط المقاطع بسطح** (Loft في Rhino، أو Bridge Edge Loops في Blender بعد تحويل المنحنيات إلى mesh)، ثم Mirror على Y.
